# Futile – The Most Pointless Website Ever

A website that does absolutely nothing useful.  
Click a button. Watch numbers go up. Read random messages. Achieve nothing.


---

## Purpose

There is none. That's the point.

This website exists to:
- Waste your time
- Count your pointless clicks
- Display sarcastic messages
- Remind you that you could be doing something productive

---

## How to Use

1. Open the website
2. Click the button
3. Repeat steps 2-3 indefinitely
4. Question your life choices

**That's it. No goals. No rewards. No meaning.**

# Flippy Floppy 

A fast-paced game inspired by Flappy Bird. Control the bird, dodge pipes, and get the highest score. 

## How to Play?

Fly through as many pipe gaps as possible. Each pipe pair passed gives 1 point.
Hit the ground, ceiling, or any pipe.
Click the FLAP AGAIN button or press any control after game over.

### **Note**: **If you see the first pipe blocked, then try refreshing the page.**

## Getting Started

1. Save the game code as index.html.
2. Double‑click the file; it opens in your default web browser.
3. Start flapping!

No internet connection or external libraries required.

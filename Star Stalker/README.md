# Star Stalker

A fast‑paced arcade game built in pure HTML. Catch the Stars, Avoid the Bombs

## How to Play

- Catch as many ⭐ as possible while avoiding 💣.
- Each star caught gives 1 point.
- Catching a single bomb ends the game.
- Click the RESTART button.

>  The game speeds up every 5 points – how high can you score?


## How to Run

1. Download the `index.html` file.
2. Double‑click it – opens in your default web browser.
3. Start catching stars immediately – no installation, no server needed.
